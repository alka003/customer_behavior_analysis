\section*{📖 Overview}
This project analyzes the overall \textbf{Sales and Profit performance} using Microsoft Excel. It includes data loading, cleaning, pivot table creation, and a fully interactive dashboard to uncover trends such as top-performing categories, regional variations, and profitability insights.  
This project highlights strong skills in Excel-based analytics and dashboard development.

\section*{🧾 Dataset}
\begin{itemize}[leftmargin=*]
    \item \textbf{File Name:} Sales and Profit Dashboard Data.xlsx
    \item \textbf{Format:} Excel (.xlsx)
    \item \textbf{Key Columns:}
    \begin{itemize}
        \item Order Date
        \item Product Category \& Sub-Category
        \item Sales Amount
        \item Profit / Loss
        \item Customer Name
        \item Region
        \item Quantity Sold
    \end{itemize}
\end{itemize}

\section*{🔍 Project Steps}

\subsection*{1. Data Loading}
\begin{itemize}
    \item Loaded dataset into Excel and converted it into a structured table.
    \item Checked data types, column headers, and missing values.
\end{itemize}

\subsection*{2. Data Cleaning}
\begin{itemize}
    \item Removed duplicate records.
    \item Corrected inconsistent formatting.
    \item Handled missing values.
    \item Standardized date and numeric fields.
\end{itemize}

\subsection*{3. Pivot Table Creation}
\begin{itemize}
    \item Sales by Category
    \item Profit by Sub-Category
    \item Region-wise Sales Performance
    \item Customer-wise Revenue
    \item Top Profitable Products
\end{itemize}

\subsection*{4. Dashboard Creation}
\begin{itemize}
    \item Built an interactive Excel dashboard with:
    \begin{itemize}
        \item Pivot Charts
        \item Slicers for filtering
        \item KPIs (Total Sales, Total Profit, Quantity Sold)
        \item Clean and professional layout
    \end{itemize}
\end{itemize}
